Box Model do CSS

Definição

O Box model (modelo de caixa) é um conceito fundamental no CSS que define como os elementos são dimensionados e posicionados na pagina

NOs exemplos abaixo, ambas as caixas possuem width:300px no CSS. Mas, na pratica suas dimensões finais são diferentes

Esta caixa tem 300px de largura
