Media Queries - Desktop First

Conseito

Media Queries são regras especiais em que criamos alterações na pagina de acordo com determinadas condições (exemplo: tamanho da tela).

Essas alterações ocorrem com a configuração de breapoints.

Sd media queries são aplicadas de acordo com a estrategia usada para design responsivo, podendo:

  • Mobile First: do pequeno para o grande
  • Desktop First: do grande para o pequeno
