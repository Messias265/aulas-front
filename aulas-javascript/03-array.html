Estrutura de dados: Array

Array (ou vetor) é uma estrutura usada para armazenar uma lista ordenada de dados em uma única variavel ou constante.

Caracteristicas principais:

  • Indexação zero: o primeiro elemento SEMPRE começa no índice 0 (zero)
  • Heterogênos: você pode misturar diferentes tipos de dados (textos, números, objetos e outros arrays)
  • Tamanho dinâmico: o array aumenta ou diminui automaticamente conforme você adiciona ou remove itens.
  • Arry dentro de array se torna uma matriz
